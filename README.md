# GAN-Augmentation-Inverse-PSC
Official implementation of a two-stage framework for Perovskite Solar Cells: Unconditional GAN for data augmentation and Weighted AC-GAN for targeted inverse design, addressing Small Data limitations.

### Main Notebook: GANs_and_cGANs.ipynb

1.  **DATA GENERATION - TRAINING:** Implementation and training of the Unconditional GAN to learn the underlying probability distribution of the experimental data. Crucially, this stage performs the **generation of synthetic samples** used to densify the dataset, which constitutes the basis for the Data Augmentation strategy applied in subsequent regression tasks.
2.  **DATA GENERATION - PERFORMANCE EVALUATION:** Comparative analysis of generative fidelity. The proposed GAN is evaluated against the baseline **Gaussian Mixture Models (GMM)** and the ground truth (Real Data) using topological metrics (t-SNE) and statistical divergence tests.
3.  **DATA AUGMENTATION ON REGRESSION:** Validation of the synthetic data utility. This section benchmarks XGBoost regressors trained on "Real Data" versus "Real + GAN Augmented Data" to quantify improvements in predictive accuracy (RMSE) and model generalization.
4.  **VIRTUAL LABORATORY TRAINING:** Calibration of the proxy XGBoost model used to simulate experimental outcomes. This "Virtual Laboratory" serves as the oracle for validating candidate recipes during the inverse design phase.
5.  **TARGETED INVERSE DESIGN OF SYNTHESIS PARAMETERS:** Training of the **Weighted AC-GAN**. This section implements the novel inverse frequency-based loss function designed to handle the "Small Data" imbalance and enable conditional generation.
6.  **VALIDATION OF INVERSE DESIGN:** Execution of Monte Carlo simulations ($N=1000$ iterations per target) to validate the continuous generation of synthesis recipes across the efficiency spectrum (10% - 21%).
7.  **ROBUSTNESS TESTING OF THE INVERSE DESIGN:** Stress testing of the framework by introducing random noise (ranging from 0% to 10%) into the synthesis parameters to evaluate the stability of the inverse mapping.

### Main Notebook: GANs_and_cGANs_for_Perovskite_Solar_Cells.ipynb
Updated version of “GANs_and_cGANs”: validation using Hellinger and MMD with different parameters, testing for diversity, memorization, and correlation preservation, comparison with the baseline (GMM) in data augmentation, and the addition of another virtual lab using Random Forest

### Datasets
Contains the three essential CSV files required to reproduce the experiments:

* **`Data_train.csv`**: The primary experimental dataset used to train the generative models (GAN/AC-GAN) and the Virtual Laboratory (80% split).
* **`Data_test.csv`**: The hold-out dataset used exclusively for validating the predictive models and evaluating generalization capabilities (20% split).
* **`Data_samples.csv` (Baseline)**: Synthetic samples generated by Gaussian Mixture Models (GMM) derived from previous research. These are used as the baseline benchmark to demonstrate the topological superiority of the adversarial approach.
